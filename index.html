DEPLOYMENT

GitHub Pages 3 步快速部署上線

本單頁專案為純前端零依賴（Vanilla HTML/CSS/JS）架構，推送到 GitHub 倉庫即可一鍵發布！

STEP 1

初始化並推送到 GitHub

在專案目錄執行 Git 指令建立倉庫並推送程式碼：

git init
git add .
git commit -m "feat: deploy AI Video Skills Portal"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
STEP 2

啟用 GitHub Pages 託管

前往你的 GitHub 專案頁面：

  • 點擊頂部標籤 Settings（設定）。
  • 在左側選單中找到 Pages。
  • 在 Build and deployment 區塊下的 Source 選擇 Deploy from a branch。
  • Branch 選擇 main，目錄選擇 / (root)，點擊 Save。
STEP 3

立即取得線上訪問網址！

等待約 30 秒 GitHub Actions 自動構建完成，即可透過以下公開網址線上瀏覽：

https://<your-username>.github.io/<your-repo-name>/

支援自訂網域（Custom Domain）與 HTTPS 憑證自動加密！
